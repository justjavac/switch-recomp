# SwitchRecomp

Switch 游戏原生重编译项目导航站。

线上地址：<https://recomp.denohub.com>

很多 Nintendo Switch 游戏正在被社区通过静态重编译（recompilation）移植到 PC、Android 和 iOS，但这些项目分散在 GitHub、GitLab 的各个仓库里。SwitchRecomp 以「游戏」为单位整理这些项目，帮助你快速判断一款游戏有没有可用移植、支持哪些设备、哪个项目更值得先试。

## 你可以在这里做什么

- 搜索游戏，查看它有哪些社区移植项目
- 按 Windows、Linux、macOS、Android、iOS / iPadOS 浏览
- 按塞尔达传说、宝可梦、超级马力欧、密特罗德等系列浏览
- 查看项目状态、支持平台、Star 数与最近更新时间
- 在游戏详情页直接看到推荐结论、常见问题和相关游戏
- 发现近期活跃的移植项目

当前收录 35 款游戏、50 个社区项目。

## 项目状态说明

- 可玩：主要流程已经可以运行
- 测试版：可以运行，但可能存在菜单、性能或兼容性问题
- 实验性：仍处于早期阶段，暂不建议作为主要游玩方式

状态来自项目公开说明，不代表当前构建一定可用。

## 使用建议

1. 在首页搜索游戏名称，或按平台、系列浏览。
2. 进入游戏详情页，先看推荐结论，再对比其他项目的平台和状态。
3. 点击项目后会先进入站外链接提示页，确认后在新窗口打开原始仓库。
4. 下载、安装和使用方法以项目仓库的 README 与发布页为准。

## 重要说明

本站是非官方粉丝项目，与 Nintendo 及相关游戏发行商无关联。

- 不提供游戏本体、ROM、密钥、固件或安装包
- 所有项目信息来自公开仓库，本站只做整理与索引
- 游戏名称、封面与商标归各自权利方所有
- 使用移植项目前请合法购买游戏并自行转储
- 项目状态与兼容性会随版本变化，请以仓库最新说明为准
